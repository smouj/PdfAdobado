PdfAdobado portable mode

While this file sits next to pdfcraft.exe, PdfAdobado keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfAdobadoData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PdfAdobado with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\PdfAdobado and
%LOCALAPPDATA%\PdfAdobado) instead. If PdfAdobadoData can't be written (for example on a read-only
drive), PdfAdobado says so and uses the per-user folders instead.
